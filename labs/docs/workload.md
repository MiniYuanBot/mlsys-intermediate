# 实验工作量与时间安排

本表由 [workload_audit.py](../tools/workload_audit.py) 对成对的 `BEGIN TODO` / `END TODO` 区域自动统计，2026-10-18 重新生成，可用文末命令复算。**只计需要学生实现的参考区域**，测试、benchmark、接口、注释和课程文字都不算填空量。

有效行（ELOC）是非空物理行，排除纯注释、预处理指令和只含括号或标点的行。它是可复算的规模代理，不是语义复杂度，也不要求学生写出同样的行数。统一格式后再计数，避免长行或换行风格扭曲对照。

## 复查命令

```bash
python tools/workload_audit.py --output results/workload.json
python tools/run.py --lab 1 --impl student --mode test --part A
python tools/run.py --lab 1 --impl reference --mode test --part A
```

命令在 `labs/` 下执行（从仓库根目录运行时写 `python labs/tools/workload_audit.py`）。标记配对缺失、编号重复、某阶段没有 TODO、参考实现里还留着未实现的桩，都会让审计失败。代码行数只帮助估计实现规模；算法正确性与实验分析仍按各 lab 的 `grade.md` 检查。参考实现的试运行范围见[验证说明](validation.md)。
