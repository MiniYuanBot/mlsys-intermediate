# 交付验证原始证据

这里保存参考测试、benchmark 和额外编译实验的原始运行记录，以及少量诊断图。这些记录证明提供的教学程序已实际运行，但不代表论文 artifact 的完整复现，也不代表用户已完成作业。

每条记录含具体命令、环境、源码哈希、stdout/stderr、退出状态。benchmark 的 CSV/JSON 行可在 `labs/` 目录用 `python tools/extract.py` 提取。`compile-*` 的跨进程磁盘编译缓存可能复用，所以 `first_call_ms` 不等于完全无缓存编译成本。学生骨架的烟雾检查会因 TODO 尚未实现而失败，这是预期行为。

当前目录的第一版记录保留原样，其中的 cwd、源码哈希和输出路径可能对应目录重构前的状态；旧日志不会改写为重新执行的结果。本次修订的重新验证另存 `revision2/`，见上级 [验证说明](../validation.md)。

模型 probe 的 config 哈希不代表权重校验和，prompt 使用合成的教学文本。由于每步都同步并开启 K/V dump，测量结果不能用于判断在线性能。完整二进制 K/V dump 留在本地 results 目录，不随证据目录归档。
