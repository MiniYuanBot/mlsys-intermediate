## 阅读动作（计入 30h）

1. 在 MegaBlocks 的 `indices_and_bins` 旁写出 A2 的 count/prefix/scatter 三步，解释它的 GPU 排序与本 lab CPU 排序的差别。
2. 在 `permute_and_compute` 里找到 gather → MLP → scatter，对照 C2，确认 route 权重是在**哪一步**应用的——别让 up 和 down 各乘一次。
3. 对照三份 router 实现，写出“选择分数”和“权重”分别取自哪个张量；特别确认 DeepSeek-V3 的 bias 出现在哪一行、不出现在哪一行。
4. 读 MoE-Infinity 配置里 window byte budget 与 inflight byte budget 的区别，写出本 lab 用 B6（单次选择字节）加 B1（驻留预算）会遗漏哪一种拥塞。
5. 在 CUDA 文档里找到 pageable 异步拷贝退化那一句抄进笔记，然后用 R4 的 pinned/pageable 两行数据验证它。

## 可视化与进一步实验

- [NVIDIA, How to Overlap Data Transfers](https://developer.nvidia.com/blog/how-overlap-data-transfers-cuda-cc/)：**只看 C1060 面板**（单 copy engine，与本机 `asyncEngineCount=1` 同构）。文中的时间是那些历史设备的，不能套到 RTX 4060。
- [NVIDIA, How to Optimize Data Transfers](https://developer.nvidia.com/blog/how-optimize-data-transfers-cuda-cc/)：pageable → pinned 的 staging 示意图与带宽表，对照 R4 实测的 12.6 / 11.6 GB/s。
- [HF, Mixture of Experts Explained](https://huggingface.co/blog/moe)：`01_moe_layer.png`（路由结构）与 `11_expert_matmuls.png`（block-sparse）。
- [A Visual Guide to Mixture of Experts](https://newsletter.maartengrootendorst.com/p/a-visual-guide-to-mixture-of-experts)：router → top-k → 加权求和那一组图。
- [Nsight Systems 文档](https://docs.nvidia.com/nsight-systems/UserGuide/index.html)：真实的 H2D / kernel 时间线。它是厂商工具，不称作开源软件；WSL2 上是 CLI-only preview，`.nsys-rep` 要在 Windows 的 GUI 里打开。
- [Perfetto](https://ui.perfetto.dev/)：挑战项里把 B7 的事件导成 trace JSON 后查看；**不得**把模拟 trace 的标签改成 CUDA。
- [本课程资源库](../../course/readings/visualizations.md)、[源码版本对照](../../course/readings/code-map.md)。
