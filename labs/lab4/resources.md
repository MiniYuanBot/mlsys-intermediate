## 带问题阅读

1. 在 HF `update_candidate_strategy` 里找到 heuristic 的“全部接受加 2、否则减 1”规则和 confidence threshold 的在线重拟合，说明为什么不把阈值设成 0 时测不到固定 $k$。
2. 在 `request_manager.cc` 里画出“请求约束 → 候选预算 → token 选择”的流程，指出与 B5、B6、C3 的三个不同点。
3. 读 vLLM metrics 的定义，用自己的 trace 算出 vLLM 会报告的 per-position 接受率，再换算成 $a_j$。
4. 估计 AdaServe artifact 的完整运行资源（4 块 A100-80G），说明为什么本 lab 只读脚本、只重写小机制。
