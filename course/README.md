## 使用方法

1. 用[选题地图](guides/directions.md)看九个方向的优先级与硬件要求，按[路线图](guides/roadmap.md)选主方向。
2. 从[课程索引](index.md)打开讲义 `modules/0N-*.md`：按小节读，每节后先做随堂自测，再展开核对要点；读完用文末“自测清单”检查。
3. 做配套 lab，见[实验索引](../labs/index.md)。
4. 写周报、实验记录和提案时用 `templates/` 下的模板。
