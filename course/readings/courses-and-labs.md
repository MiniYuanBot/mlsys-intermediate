## LCPU AI Infra Seminars 与本课程的对应

[LCPU Infra Seminars](https://infra.seminars.lcpu.dev/) 由北京大学学生 Linux 俱乐部与北京大学未名超算队合办，站点内容采用 CC BY-NC-SA 4.0；作业在[活动仓库](https://github.com/lcpu-club/wmhpc-training-camp-x-lcpu-ai-infra-seminars)，仓库没有声明许可证。仓库的 AI 使用政策是“AI 可以帮你理解，但不能替你实现”。仓库 README 写的讲授顺序是：GPU 编程，然后 memory hierarchy、Tensor Core、软件流水、DSL 与编译器、通信、推理系统、RL 系统。
