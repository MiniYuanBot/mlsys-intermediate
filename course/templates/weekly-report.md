# 第 N 周（日期范围）

- 本周 36h 的实际分配：阅读 / 实现 / 实验 / 写作 / 沟通。
- 上周假设、本周最重要的证据（先写结论和限制）：
- 一个正确性进展：测试/失败案例链接。
- 一张图：命令、原始数据、硬件与统计口径。
- 一个负结果：排除了什么解释，仍有何不确定性。
- 最近邻更新：是否发现重复工作或更强 baseline。
- 卡点：最小复现、已尝试的方法、希望得到的具体反馈。
- 下周三个交付：每项包含文件/实验/验收时间，不写泛泛“继续读论文”。
- 需要资源：用途、预算、停止条件。

## 资料汇总

论文卡、实验记录、commit、提案。
